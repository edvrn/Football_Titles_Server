================================================================================
РУКОВОДСТВО ПО РЕДАКТИРОВАНИЮ SVG ШАБЛОНОВ
================================================================================

Все шаблоны находятся в папке: public/templates/

ВАЖНО: 
- Не удаляйте переменные в фигурных скобках {{variable}}
- Цвета команд задаются через переменные {{homeTeamColor}} и {{awayTeamColor}}
- В панели управления можно выбирать любые цвета
- Не используйте фиксированные цвета для фона команд

================================================================================
1. scoreboard.svg - Табло
================================================================================

ОБЯЗАТЕЛЬНЫЕ ПЕРЕМЕННЫЕ (не удалять!):
{{homeTeamName}}     - Название домашней команды
{{awayTeamName}}     - Название гостевой команды  
{{homeTeamScore}}    - Счет домашней команды
{{awayTeamScore}}    - Счет гостевой команды
{{homeTeamColor}}    - Цвет домашней команды (HEX, меняется из панели)
{{awayTeamColor}}    - Цвет гостевой команды (HEX, меняется из панели)
{{matchTime}}        - Текущее время матча (MM:SS)
{{additionalTimeText}}- Текст добавленного времени (+2')
{{halfText}}         - Текст статуса (1-й тайм, Перерыв, и т.д.)

ГДЕ ИСПОЛЬЗУЮТСЯ ЦВЕТА:
1. Градиент фона:
   <stop offset="0%" stop-color="{{homeTeamColor}}" stop-opacity="0.3" />
   <stop offset="100%" stop-color="{{awayTeamColor}}" stop-opacity="0.3" />

2. Фон блока домашней команды:
   <rect fill="{{homeTeamColor}}" opacity="0.15" />

3. Фон блока гостевой команды:
   <rect fill="{{awayTeamColor}}" opacity="0.15" />

ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ ЦВЕТОВ:
   - Можно использовать в обводке: stroke="{{homeTeamColor}}"
   - Можно использовать в тексте: fill="{{homeTeamColor}}"
   - Можно использовать в градиентах: stop-color="{{homeTeamColor}}"

ОПЦИОНАЛЬНЫЕ ЭЛЕМЕНТЫ (можно добавлять любые):
- Логотипы команд (фиксированные, не зависят от цвета)
- Декоративные рамки с цветом команды
- Цветные полосы

РЕКОМЕНДАЦИИ ПО РАЗМЕРАМ:
- Общая ширина: 800px
- Общая высота: 200px
- Шрифт названий команд: 32px, Arial/Bold
- Шрифт счета: 56px, Courier New/Bold
- Шрифт времени: 34px, Courier New/Bold

================================================================================
КАК ЭКСПЕРИМЕНТИРОВАТЬ С ЦВЕТАМИ
================================================================================

1. ИЗМЕНЕНИЕ ПРОЗРАЧНОСТИ:
   fill="{{homeTeamColor}}" opacity="0.2"

2. ИСПОЛЬЗОВАНИЕ ДЛЯ РАМКИ:
   stroke="{{homeTeamColor}}" stroke-width="3"

3. ГРАДИЕНТ С ЦВЕТОМ КОМАНДЫ:
   <linearGradient id="teamGrad">
       <stop offset="0%" stop-color="{{homeTeamColor}}" />
       <stop offset="100%" stop-color="#ffffff" />
   </linearGradient>

4. ТЕКСТ ЦВЕТОМ КОМАНДЫ:
   <text fill="{{homeTeamColor}}">Текст</text>

5. ТЕНЬ С ЦВЕТОМ КОМАНДЫ:
   <filter id="shadow">
       <feDropShadow dx="2" dy="2" stdDeviation="3" flood-color="{{homeTeamColor}}"/>
   </filter>

================================================================================
ПРОВЕРКА РАБОТЫ ЦВЕТОВ
================================================================================

1. Запустите сервер
2. Откройте панель управления http://localhost:3000
3. Измените цвет любой команды в панели
4. Цвет табло должен измениться автоматически

Если цвет не меняется:
- Проверьте что в шаблоне используется {{homeTeamColor}}
- Перезапустите сервер после изменения шаблона
- Проверьте консоль сервера на ошибки

================================================================================
ОБЩИЕ ПРАВИЛА ДЛЯ ВСЕХ ШАБЛОНОВ
================================================================================

1. НЕ УДАЛЯЙТЕ ПЕРЕМЕННЫЕ:
   Все что внутри {{ }} - это переменные, они будут заменены сервером

2. МОЖНО МЕНЯТЬ:
   - Цвета (но для команд используйте переменные)
   - Размеры текста и элементов
   - Шрифты (стандартные: Arial, Courier New, Impact)
   - Позиции элементов (координаты x, y)
   - Добавлять рамки, тени, градиенты
   - Добавлять логотипы и иконки

3. НЕ РЕКОМЕНДУЕТСЯ:
   - Использовать внешние шрифты (могут не загрузиться)
   - Сложные CSS стили внутри <style>
   - JavaScript код (не будет выполняться)
   - Внешние изображения без проверки доступности

================================================================================
ПРИМЕРЫ КАСТОМИЗАЦИИ С ЦВЕТАМИ
================================================================================

1. Добавление цветной полосы сверху:
   <rect x="0" y="0" width="800" height="5" fill="{{homeTeamColor}}"/>
   <rect x="0" y="195" width="800" height="5" fill="{{awayTeamColor}}"/>

2. Цветная рамка вокруг табло:
   <rect x="5" y="5" width="790" height="190" fill="none" stroke="{{homeTeamColor}}" stroke-width="2"/>
   <rect x="405" y="5" width="390" height="190" fill="none" stroke="{{awayTeamColor}}" stroke-width="2"/>

3. Градиент с цветами команд:
   <linearGradient id="teamSplit" x1="0%" y1="0%" x2="100%" y2="0%">
       <stop offset="0%" stop-color="{{homeTeamColor}}"/>
       <stop offset="50%" stop-color="#333"/>
       <stop offset="100%" stop-color="{{awayTeamColor}}"/>
   </linearGradient>

4. Цветной текст счета:
   <text fill="{{homeTeamColor}}">{{homeTeamScore}}</text>
